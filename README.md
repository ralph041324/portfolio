# Personal Portfolio

CC107 Activity 4: Application Development - Web Platforms.

A single-page portfolio built with HTML, CSS, and JavaScript.

## Features
- Semantic HTML5 layout (header, nav, main, section, footer)
- Responsive design using Flexbox, Grid, and media queries
- Dark/light mode toggle (saved in the browser)
- Hamburger menu on mobile
- Smooth scrolling between sections

Live site: https://ralph041324.github.io/portfolio/
